# DeepGPO
DeepGPO is a deep learning framework for the prediction of MS/MS spectra of O-/N-glycopeptides. 
# User Guide
For detailed step-by-step instructions on how to get started with DeepGPO, please refer to [User_guide.md](https://github.com/lmsac/DeepGPO/blob/main/User_guide.md).
